# AD - Acceso a Datos

## Sesion 01 - Entorno y primer script (PHP)

Carpeta `curso-php/`:

- `index.php` - primer script: una isla de PHP dentro de HTML que imprime "Hola mundo desde PHP".
- `islas.php` - bucle `for` con sintaxis alternativa (`for: ... endfor;`) mezclado con HTML.

Para ejecutarlos hace falta Apache (XAMPP) con la carpeta servida desde `htdocs`.
