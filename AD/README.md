# AD - Acceso a Datos

## Sesion 01 - Entorno y primer script (PHP)

Carpeta `curso-php/`:

- `index.php` - primer script: una isla de PHP dentro de HTML que imprime "Hola mundo desde PHP".
- `islas.php` - bucle `for` con sintaxis alternativa (`for: ... endfor;`) mezclado con HTML.

Se sirven desde `http://localhost/AD/curso-php/` gracias a un junction que enlaza
`C:\xampp\htdocs\AD` con la carpeta `AD` del repo. No hay copias: es el mismo archivo.

## Sesion 29/09 - Funciones y paso por referencia

- `index2.php` - funciones: `saludar`, numero mayor de 2 y de 3.
- `index3.php` - hipotenusa, paso por referencia (`&`) y la practica `calcular()`.

## Sesion 29/09 y 05/10 - Formularios con `$_POST`

- `index4.php` -> `index5.php` - formulario de un campo y pagina que muestra lo recibido.
- `index6.php` -> `index7.php` - dos campos y boton `+`: suma los numeros.
- `index8.php` -> `index9.php` - calculadora con 4 botones (x, /, +, -): segun el boton pulsado hace una operacion u otra.

Se prueban abriendo el formulario (`index4`, `index6` o `index8`) y pulsando el boton.
