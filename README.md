## Módulos

| | Módulo | Qué se construye | Stack |
|:-:|---|---|---|
| **DI** | [Desarrollo de Interfaces](DI) | Aplicaciones de escritorio con interfaz gráfica | Java · JavaFX · FXML · Scene Builder · Maven |
| **AD** | [Acceso a Datos](AD) | Aplicaciones web que leen y guardan datos | PHP · MySQL · XAMPP |

| **PSP** | [Programación de Servicios y Procesos](PSP) | Programas concurrentes y servicios en red | Python · procesos · hilos · sockets |

## Cómo ejecutar

| Módulo | Cómo |
|---|---|
| **DI** | Abrir la carpeta del proyecto en IntelliJ. Los proyectos Maven se lanzan con `mvn javafx:run` o desde su clase `MainApplication` |
| **AD** | Copiar o enlazar `AD/` dentro de `htdocs` de XAMPP y abrir `http://localhost/AD/` |
| **PMyDM** | `node archivo.js` para los ejercicios; `npx expo start` para las apps |
| **PSP** | `python -m venv .venv`, activar el entorno y `python archivo.py` |
| **SGE** | Seguir [`SGE/odoo-setup.sh`](SGE/odoo-setup.sh) y [`SGE/Despliegue_Odoo_SGE.pdf`](SGE/Despliegue_Odoo_SGE.pdf) |
